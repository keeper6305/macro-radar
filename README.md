- **실현손익 종목별 합산**: 내역 시트에 `월별 / 종목별` 보기 전환. 종목별은 같은 종목의 여러 매도를 **통화별로** 묶어 `3건 · 2/3 (승률 67%) · 평균 +1.0%`와 종목 합계 손익을 한 줄에 보여 주고, 줄을 펼치면 개별 매도(수량×단가·삭제)가 나온다. 가장 큰 |손익| 종목이 위·첫 줄만 펼침, 통화가 섞이면 `원화/달러` 라벨. 저장 없이 매번 화면에서 계산(새 저장 필드 0개).
- **가상자산 신선도 정정**: 코인 카드·지표 코인 줄이 `업데이트 11/26 16:05`(국내 마감)을 쓰던 것을, 실제 코인 스냅샷이 실린 07:00 빌드 시각(`sessionStamps.crypto` → 없으면 `us`)으로 바꿨다. 24시간 시장이라 `기준 11.26 종가` 대신 `기준 11.26 스냅샷`으로 표기하고, `title`에 “24시간 거래 · ↻로 현재가”를 붙였다. 국내·미국 지표는 그대로.
