## v11 (2026-11-25) 주요 변경

포트폴리오·매매 복기·지표 비교를 실전 앱 수준으로 — 벤치마킹은 TradingView(Holdings의 Daily gain·Performance, Portfolio의 benchmark 비교), Koyfin(performance vs benchmark), Investing.com·Fidelity(오늘 손익과 총 손익의 구분)의 **UX 구조만** 참고했고 문구·콘텐츠는 복사하지 않았습니다.

- **오늘 손익(전일 종가 대비)**: 포트폴리오 카드에 `오늘 손익 +44,515원 (+5.21%) · 원화 -640원 · 달러 +$33.64` 줄을 추가. 등락률로 전일 종가를 역산해 `오늘 평가액 − 전일 평가액`을 계산하고, 총 평가손익(매입 대비)과 섞이지 않게 라벨·설명을 분리. 두 통화가 있으면 환율로 합산하고 통화별도 병기, 긴 설명은 `title`로.
- **기간 성과 · 지수 대비**: 종목 상세에 1개월·3개월·6개월 수익률과 **같은 시작일부터** 계산한 지수(코스피·코스닥·나스닥·BTC) 수익률, 그 차이(%p)를 표로. TradingView Performance·Koyfin benchmark 비교를 우리 데이터(6개월 일별 종가 + 지표 탭 지수 시계열)로 옮김.
- **실현손익 통화별 승률**: 원화·달러 기록이 섞여 있을 때 `합산` 줄 아래에 통화별 `이긴 매도 n/m (승률) · 평균`을 따로 표시(한 통화면 기존 그대로).
- **탭 제목·홈 아이콘 배지**: 오늘의 매수 후보가 있으면 탭 제목이 `(1) 거시경제·투자 레이더`로 바뀌고, 설치된 PWA에서는 Badging API(`setAppBadge`)로 아이콘 배지도 표시(실패는 무시). 앱 밖에서도 후보를 알 수 있게.
- **브리핑 반영 대기 → 지금 새로고침**: 반영 대기 상자에 `↻ 지금 새로고침` 버튼과 안내. 데이터를 다시 받아 새 버전이면 적용, 그대로면 `새 데이터가 아직 없습니다 · 현재 … 기준`을 알린다.
- **도감 복습 필터**: 상태 필터에 `복습 n` 칩 추가 — 완료했지만 복습 주기(3/7/14일)를 지난 카드만 모아 보고, 그 상태로 퀵 테스트(10장 세션)를 바로 시작.
- **실시간 시세는 ↻ 버튼에서만**: 부팅 때 외부 API(Yahoo·CoinGecko)를 부르지 않는다. 정기 반영(07:00·16:00) 데이터로 충분하고, Yahoo 호가가 한도(429)로 막히면 열 때마다 콘솔 오류만 쌓였다. ↻는 코인·주식을 함께 갱신하며 주식 호가가 응답하지 않으면 토스트로 알린다(거짓 성공 없음).
- `localStorage` 키·구조 변경 없음(새 저장 필드 0개 — 모두 화면 상태·계산). 도감 10장 세션·뒤로가기 2회 종료 그대로. 서비스 워커 캐시 `macro-radar-v11-0`.
